# 🥚 계란값 예측 프로젝트

조류독감 발생 여부와 원/달러 환율을 바탕으로 **계란 30개(한 판) 가격**을 예측하는 머신러닝 프로젝트입니다.

## 📌 만든 이유

장을 볼 때마다 계란값이 크게 오르내리는 게 평소에 불편했습니다. AI를 배우면서 실생활의 문제를 직접 다뤄보고 싶었고, 흥미 있던 분야라 "계란값을 예측할 수 있을까?"라는 생각으로 시작했습니다.

## 🧠 어떻게 동작하나

입력 변수 두 가지로 계란 가격을 예측합니다.

- **조류독감 발생 여부** — 발생 시 살처분으로 공급이 줄어 가격이 오름
- **원/달러 환율** — 닭 사료(옥수수·대두)가 대부분 수입이라, 환율이 오르면 사료비를 거쳐 가격에 영향

선형회귀(Linear Regression) 모델을 사용해, 각 변수가 가격에 주는 영향을 숫자로 해석할 수 있도록 했습니다.

## 🛠 기술 스택

| 분류 | 사용 기술 |
|---|---|
| 언어 | Python |
| 데이터 처리 | pandas |
| 머신러닝 | scikit-learn (LinearRegression) |
| 모델 저장 | joblib |

## 📊 성능 평가

- 학습용 80% / 테스트용 20%로 분리해 검증
- **R²(결정계수)** — 모델이 가격 변동을 얼마나 설명하는지
- **RMSE** — 평균 예측 오차 (단위: 원)

## 🚀 실행 방법

```bash
# 1. 라이브러리 설치
pip install pandas scikit-learn joblib

# 2. 모델 학습 및 저장
python train.py

# 3. 예측 실행
python predict.py
```
